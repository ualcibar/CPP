## 📖 About

This repository gathers all 10 modules of the **C++ piscine** from 42's Common Core. Each module builds on the previous one, progressively introducing C++ from the ground up — from basic classes and memory management to templates and the Standard Template Library (STL).

## 🧩 Modules

| Module | Topic | Description |
|---|---|---|
| [CPP00](./CPP00) | Namespaces, classes, member functions | Introduction to C++ classes, member functions, stdio streams, initialization lists, static and const. |
| [CPP01](./CPP01) | Memory allocation, pointers, references | Dynamic memory allocation, pointers to members, references, and the switch statement. |
| [CPP02](./CPP02) | Ad-hoc polymorphism, operator overloading | Overloading operators and implementing the orthodox canonical class form (fixed-point numbers). |
| [CPP03](./CPP03) | Inheritance | Building class hierarchies with single and multiple inheritance. |
| [CPP04](./CPP04) | Subtype polymorphism, abstract classes | Virtual functions, abstract classes and interfaces. |
| [CPP05](./CPP05) | Repetition and exceptions | Custom exception classes and exception handling. |
| [CPP06](./CPP06) | Type conversion | The four C++ casts: `static_cast`, `dynamic_cast`, `reinterpret_cast`, `const_cast`. |
| [CPP07](./CPP07) | Templates | Function and class templates for generic programming. |
| [CPP08](./CPP08) | Templated containers & iterators | Introduction to the STL: containers, iterators and algorithms. |
| [CPP09](./CPP09) | STL containers & algorithms | Solving a practical problem using STL containers and algorithms in depth. |

## 🛠️ Tech stack

- **Language:** C++98
- **Build:** Makefile per module
